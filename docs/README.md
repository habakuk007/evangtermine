# Dokumentation: Evangelische Termine

Diese Dokumentation gehört zum WordPress-Plugin „Evangelische Termine“ (Version 3.5). Sie beschreibt den Stand der Version 3.5; spätere Versionen können davon abweichen. Die Texte für Anwender sind auf Deutsch, die Seiten für Entwickler auf Englisch.

Eine kurze Beschreibung steht auch in der [README](../README.md) und in der `readme.txt` (die Seite des Plugins auf WordPress.org).

## Für Anwender (Deutsch)

| Seite | Inhalt |
|-------|--------|
| [Installation](de/installation.md) | Plugin installieren, aktivieren und die erste Einrichtung |
| [Einstellungen](de/einstellungen.md) | Die sieben Einstellungen mit Standardwerten und Einschränkungen |
| [Shortcodes](de/shortcodes.md) | `et_veranstalter`, `et_teaser`, `et_panels`, `et_minical` mit je einem Beispiel |
| [Widget](de/widget.md) | Die Felder des Widgets „Evangelische Termine“ |
| [Parameter](de/parameter.md) | Alle Parameter je Shortcode und Widget, mit Standardwert und Beispiel |
| [Eigenes CSS](de/eigenes-css.md) | Eigene CSS-Datei, `nocss`, die `et_`-Klassen |
| [Häufige Fragen und Probleme](de/faq.md) | Fehlermeldungen, gesperrte Verbindungen, Cache, Suche |
